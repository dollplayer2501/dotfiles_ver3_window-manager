# 01. Workspaces and layouts


## 1. Basic Approach

The following workspaces and built-in layouts are configured.
I have set up multiple layouts, but I hardly ever use any of them except for the bolded one.
Additionally, depending on the layout, a "pilot implementation" status is also included.

| Workspace<br />Number | Workspace<br />Label | Layouts | Purpose |
| :---: | :--- | :---- | :---- |
| 1 | 1.terminal | **TreeTab**<br />VerticalTile<br />Max | Mainly using the terminal, Kitty. |
| 2 | 2.code     | **Max**<br />MonadWide<br />MonadTall | Using almost exclusively the IDE, Code/OSS. |
| 3 | 3.web      | **TreeTab**<br />Max | Web-related applications, Firefox, Thunderbird, KeePassXC. |
| 4 | 4.tool     | **MonadWide**<br />Max<br />MonadTall<br />Floating | File manager, Thunar. |
| 5 | 5.misc     | **Max**<br />TreeTab<br />Floating| Various applications, including LibreOffice, GIMP, Steam. |
| 9 | 9.null     | **Matrix**<br />Columns<br />Floating| |

As for workspaces 6 through 8, they are currently unassigned; they remain from a time when I was experimenting with a multi-monitor setup.
